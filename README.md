# Vibe Sudoku

A beautiful, interactive Sudoku puzzle generator built with vanilla JavaScript. Play unlimited Sudoku puzzles directly in your browser!

## Features

- **Fresh Puzzles Every Time**: Each page refresh generates a brand new puzzle
- **4 Difficulty Levels**: Easy, Medium, Hard, and Expert
- **Interactive Gameplay**:
  - Click cells to enter numbers
  - Arrow keys for navigation
  - Real-time validation
  - Hint system
  - Solution checker
- **Modern UI**: Beautiful gradient design with responsive layout
- **No Backend Required**: Runs entirely in the browser using sessionStorage

## How to Play

1. Open `index.html` in your web browser
2. Select your preferred difficulty level
3. Click on empty cells and enter numbers 1-9
4. Use arrow keys to navigate between cells
5. Click "Check Solution" to validate your answers
6. Click "Hint" if you need help
7. Click "New Game" to generate a fresh puzzle

## GitHub Pages

This site is designed to be published via GitHub Pages. Simply push to your repository and enable GitHub Pages in the settings.

## Technologies Used

- HTML5
- CSS3 (with gradients and flexbox)
- Vanilla JavaScript (ES6+)
- sessionStorage API
